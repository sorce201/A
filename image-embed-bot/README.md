# بوت تحويل الصور إلى Embed + تعليقات وتفاعلات

## وش يسوي البوت؟
- أي عضو يرسل صورة بالروم المحدد → البوت يحذف رسالته الأصلية ويحط الصورة بـ Embed منسق.
- تحت الإمبيد زرين:
  - **➕ إضافة تعليق** → يفتح نافذة كتابة، والتعليق يتخزن.
  - **💬 عرض التعليقات (العدد)** → يعرض التعليقات لصاحب الضغطة فقط (رسالة خاصة/ephemeral).
- يضيف تلقائياً إيموجيات تفاعل تحت الإمبيد (👍 ❤️ 🔥 😂 - قابلة للتعديل).
- التعليقات تُحفظ بملف `comments.json` حتى لو البوت انطفى وشتغل من جديد.
- مضبوط حالياً يشتغل بروم واحد فقط: `1535938702231207956`.

---

## خطوة 1: إنشاء تطبيق البوت على Discord
1. روح لـ https://discord.com/developers/applications
2. اضغط **New Application** وسمّه أي اسم تحب.
3. من القائمة الجانبية اضغط **Bot** → **Add Bot**.
4. فعّل هذي الخيارات تحت "Privileged Gateway Intents":
   - **MESSAGE CONTENT INTENT** (مهم جداً عشان يقدر يشوف الصور)
5. اضغط **Reset Token** وانسخ التوكن (خله سري، ما تشاركه أبد).

## خطوة 2: دعوة البوت لسيرفرك
1. من نفس صفحة التطبيق روح لـ **OAuth2 → URL Generator**.
2. تحت **Scopes** اختر: `bot`
3. تحت **Bot Permissions** اختر:
   - Send Messages
   - Manage Messages (عشان يقدر يحذف رسالة الصورة الأصلية)
   - Embed Links
   - Attach Files
   - Add Reactions
   - Read Message History
4. انسخ الرابط اللي يطلع تحت وافتحه بالمتصفح واختر سيرفرك عشان يدخل البوت.
